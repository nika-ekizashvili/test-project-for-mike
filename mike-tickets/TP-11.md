## Design Decisions

### Layout Approach
- **Mobile-First**: Started with mobile design, enhanced for larger screens
- **Responsive Grid**: 12-column system on desktop, 2-column on tablet, single-column on mobile
- **Full-Width Sections**: Each section spans 100% width with contained content area

### Content Hierarchy
- Hero section as primary above-the-fold conversion point
- Features for credibility and differentiation
- How It Works for education/demonstration
- Google Sheets for integration value
- Privacy & Security for trust-building
- Install CTA as final conversion opportunity
- Footer for navigation and legal

### Conversion Strategy
- Multiple CTA placements (Hero, Install CTA section)
- Secondary goals integrated naturally throughout (docs, GitHub)
- Clear visual hierarchy emphasizing install button

### Accessibility-First
- Semantic HTML hierarchy (H1 → H2 → H3)
- WCAG 2.1 AA compliance targeted
- Keyboard navigation for all interactive elements
- Motion respects prefers-reduced-motion
- Form inputs with proper labels
