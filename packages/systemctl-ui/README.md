# @systemctl/ui

A React component library for the systemctl UI project.

## Installation

```bash
npm install @systemctl/ui
```

## Usage

### Button

```tsx
import { Button } from '@systemctl/ui';

export function MyComponent() {
  return (
    <Button variant="primary" size="md">
      Click me
    </Button>
  );
}
```

## Components

- **Button**: A flexible button component with support for variants, sizes, and loading states.
